# 🗓️タスク＆習慣管理アプリ

## 📌 概要

 個人向けのタスク管理と習慣化を支援するWebアプリです。

 タスクと習慣を一元管理し、日々のやることを整理・確認できます。
 また、進捗を可視化することでタスク消化と習慣の定着をサポートします。

***

## 🎯 作成目的

既存のタスク管理アプリは「タスクのみ」「習慣のみ」に分かれているものが多く、両者を横断して管理できない課題があると感じたため、本アプリを開発しました。

また、カレンダーアプリでも類似の管理は可能だが、習慣の実施状況を継続的に記録・可視化する機能が不足していると考えました。

そこで、タスクと習慣を統合し、将来的にはカレンダー機能と組み合わせることで、「その日の行動の重み」を判断できるような仕組みの実現を目指しています。

***
## 💡 工夫した点

### 共通化による保守性・拡張性の向上

タスクと習慣の両方を扱うため、一覧・詳細・作成など共通化できる機能は可能な限り共通化し、保守性と拡張性を意識した設計を行っています。

### ユーザー体験を意識した画面設計

データが存在しない場合と検索結果が0件の場合で表示内容を変更するなど、利用者が状況を理解しやすいUIを意識しています。

また、1画面当たりの情報量を抑えることで、直感的に操作できる画面構成を目指しています。

### 将来の機能拡張を考慮した設計

カテゴリ・重要度・タグなどの情報を扱えるよう設計し、将来的な機能追加に対応しやすい構成を意識しています。

***

## 🚀 主な機能

### タスク管理

- タスクの作成・編集・削除（CRUD）
- 期限日設定
- 検索・絞り込み機能

### 習慣管理

- 習慣の作成・編集・削除（CRUD）
- 実行チェック機能
- 実施間隔設定
- 検索・絞り込み機能

### カレンダー機能（開発中）

- 日ごとのタスク・習慣の統合表示

### ダッシュボード機能（開発中）

- 当日のタスク・習慣表示
- 週間単位での状況表示
- 習慣達成率のグラフ表示

### 通知機能（開発予定）

- タスク期限通知
- 習慣実施通知

### HTML / CSS

ユーザーが直感的に操作できる画面を目指し、UI実装に使用しています。

## 🔮 今後の実装予定

### 短期的な改善

- UI/UX改善
- 今日・今週のやることリスト機能
- 習慣達成率の可視化

### 将来的な拡張構想

#### プロジェクト（フォルダ）機能

タスクや習慣をプロジェクト単位で管理できる機能を追加し、目的ごとの達成状況を可視化できるようにする予定です。

#### カテゴリ・重要度・タグ機能

カテゴリによる分類、重要度による優先順位付け、タグによる柔軟な管理を可能にし、より高度な情報整理を実現する予定です。

また、色分けによる視覚的な識別にも対応し、操作性向上を目指しています。

#### AIアドバイス機能

蓄積した行動データをもとに、

- タスクの優先順位提案
- 習慣継続のためのアドバイス
- 行動傾向の分析

などを行い、ユーザーの意思決定を支援する機能の実装を検討しています。

個人のタスク管理にとどまらず、行動改善を支援するアプリへの発展を目指しています。
