## 🗓️タスク＆習慣管理アプリ（Project1）

### 📌 概要

 個人向けのタスク管理と習慣化を支援するWebアプリです。
 タスクと習慣を一元管理し、日々のやることを整理・確認できます。
 また、進捗を可視化することでタスク消化と習慣の定着をサポートします。

***
### 🎯 作成目的

- Djangoを使用したWebアプリ開発スキルの習得
- タスクと習慣を一元管理できるアプリの実現

***
### 🚀 主な機能

- ✅ タスク管理（CRUD、期限設定）
- 🔁 習慣管理（CRUD、実行チェック、間隔設定）
- 📊 ダッシュボード（当日・週間のタスクと習慣を表示）
- 📆 カレンダー表示
- 📈 習慣の達成状況の可視化
- 🔔 通知機能

***
### ⚙️ 使用技術

- Python
- Django
- PostgreSQL
- HTML/CSS
