## 🗓️タスク＆習慣管理アプリ

### 📌 概要

 個人向けのタスク管理と習慣化を支援するWebアプリです。
 タスクと習慣を一元管理し、日々のやることを整理・確認できます。
 また、進捗を可視化することでタスク消化と習慣の定着をサポートします。

***
### 🎯 作成目的

既存アプリは「タスクのみ」「習慣のみ」に分かれているものが多く、両者を横断して管理しにくい課題があると感じたため、本アプリを開発しました。
 
また、カレンダーアプリで使い方次第では類似の管理は可能ですが、習慣の実施状況を継続的に記録・可視化する機能
がまだ不足していると考えました。
 
そこで、タスクと習慣を統合し、将来的にはカレンダー機能と組み合わせることで、「その日の行動量」をアプリ一つで判断できるような仕組みの実現を目指しています。

👉 単なる管理ではなく、行動の可視化と意思決定支援を目的としています。

***
### 💡 工夫した点

タスクと習慣の両方を扱うため、共通化できる機能は可能な限り共通化し、保守性と拡張性を意識した設計にしました。

また、データが存在しない場合と検索結果が0件の場合でUI表示を分けるなど、細かなユーザー体験の改善にも取り組んでいます。

さらに、1画面当たりの情報量を抑えることで、直感的に操作できるUI設計を意識しています。

👉 これにより、単なる管理ツールではなく「継続利用を前提とした設計」を意識しています。

### 🚀 主な機能

- ✅ タスク管理（CRUD、期限設定）
- 🔁 習慣管理（CRUD、実行チェック、間隔設定）
- 📊 ダッシュボード（当日・週間のタスクと習慣を表示）
- 📆 カレンダー表示
- 📈 習慣の達成状況の可視化
- 🔔 通知機能
